# Windows 设备接入

1. 下载 Release 的 bundle ZIP 与 SHA256.json，校验文件并完整解压。管理员 PowerShell 运行 `deploy/Install-Desktop.ps1`；使用其他管理员账号时通过 `-DesktopUser` 指定实际桌面用户的本地账号。
2. 先检查现有 WireGuard 隧道、虚拟 IP、路由和代理，备份相关配置。已有可用隧道时优先复用，不要重新生成密钥或覆盖隧道。
3. 在服务端网页“组网设备 → 添加设备”生成入网码。复用隧道时填写该设备原有虚拟 IP；新设备自动分配时留空。入网码单次使用，10 分钟有效，请在客户端准备完成后生成。
4. 客户端“加入私网”填写 HTTPS 服务器地址、设备名称、入网码、通过可信渠道获取的服务器证书 PEM。复用时选择“接入已有隧道”并填写实际隧道名；全新设备才选择“创建新隧道”。禁止关闭 TLS 验证。
5. 核验后台服务 `NetConductorAgent`、网页设备在线状态、WireGuard 握手、虚拟 IP 与目标 TCP 服务连通性；运行客户端连接检查。对端禁用 ICMP 时，不要仅凭 ping 失败认定组网失败。
6. v0.2.0 安装器自动安装配置 OpenSSH Server、私网防火墙规则和本机 SSH 密钥；入网后后台自动追加服务端 SSH 公钥。核对网页设备的 SSH 用户和 ED25519 指纹；既有配置不会被自动替换。私网不是默认网段时，安装脚本使用 `-PrivateNetwork` 指定实际网段。不要将 SSH 直接开放到公网。
7. 网页“组网设备”提供 SSH、文件管理和 Windows 桌面入口。连接优先 WebRTC 直连，失败自动用 HTTPS/WebSocket 中转；桌面功能要求用户已登录、未锁屏且托盘运行。Linux 仅提供 SSH 与文件管理。

入网不会自动切换系统代理。需要代理时，再设置网页出口策略和客户端系统代理；保留原设置以便恢复。

管理密码、入网码、私钥、设备令牌不能进入 Git、公开 Issue 或截图。缺少入网码或可信证书时，先完成安装检查，再向管理员索取。
